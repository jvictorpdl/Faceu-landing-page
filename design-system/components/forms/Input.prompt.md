Single-line text field. 6px radius (squarer than buttons), cyan focus ring.

```jsx
<Input id="name" placeholder="Full name" />
<Input icon="search" placeholder="Search tools, manuals, publications" />
<Input tone="dark" type="email" placeholder="name@institution.edu" />
```

Wrap in `Field` for a visible label — placeholder-only fields are not acceptable in FACEU forms.
