One card per tool: glyph, status, name, one-line purpose, category + version, then Learn more / manual actions.

```jsx
<ToolCard name="FACEU Mapper" shortDescription="Builds a structured map of accessibility barriers from field surveys." category="Mapping" status="stable" version="v2.1" icon="map" href="/tools/faceu-mapper" manualLabel="User manual (PDF)" />
```

Read as a research resource, not a product: no pricing, no "Get started free". Use `tone="dark"` for the one featured tool inside a navy band. Always keep the manual action on the card — never bury documentation.
