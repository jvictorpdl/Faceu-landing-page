The action primitive — pill radius, gold gradient reserved for the one primary action in a view.

```jsx
<Button variant="primary" size="lg" iconAfter="arrow-right" chip>Explore the project</Button>
<Button variant="outline" icon="download">Download FACEU Mapper user manual</Button>
<Button variant="onDark" href="#tools">View tools</Button>
```

Variants: `primary` (gold gradient, navy label), `secondary` (navy solid), `outline` (white + hairline, gold on hover), `ghost`, `onDark` (translucent, for navy sections). `chip` adds the circular trailing-arrow disc used on hero CTAs. Label downloads descriptively — never just "Download".
