Mono-cased metadata chip: tool categories, document types, filter chips.

```jsx
<Tag tone="gold" icon="layers">Mapping</Tag>
<Tag interactive selected onClick={pick}>All tools</Tag>
```

Set in IBM Plex Mono at 12px with wide tracking — the same treatment as eyebrows, so tags read as data, not as buttons. Use `StatusBadge` for lifecycle state instead.
