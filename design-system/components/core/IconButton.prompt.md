Circular single-glyph control for carousels, search toggles, social links and card affordances.

```jsx
<IconButton icon="search" label="Search FACEU" variant="ghost" />
<IconButton icon="arrow-right" label="Next tool" variant="gold" size="lg" />
```

Always pass `label`; the glyph itself is aria-hidden. On navy sections use `variant="onDark"`.
